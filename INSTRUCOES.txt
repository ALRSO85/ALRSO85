# Cartão de atividade do GitHub

O cartão exibido no README é gerado pela GitHub Action definida em `.github/workflows/profile-summary-cards.yml`.

## Atualização

- A Action executa quando `README.md` ou o workflow mudam na branch `main`.
- Também pode ser iniciada manualmente em **Actions > GitHub Profile Summary Cards > Run workflow**.
- Uma execução diária está agendada para 03:20 UTC (00:20 no horário de Brasília).
- Os cartões são gerados em `profile-summary-card-output/` e enviados para a branch `main`.
- Todos os temas são gerados; o README escolhe entre os temas claro e escuro conforme a preferência do visitante.

## Token

Por padrão, o workflow usa `GITHUB_TOKEN`. Se ele não puder ler algum repositório necessário para gerar os cartões, configure um fine-grained personal access token com acesso somente de leitura aos repositórios necessários.

Guarde o token em **Settings > Secrets and variables > Actions** com o nome `SUMMARY_GITHUB_TOKEN`. Nunca o coloque no README, no workflow ou em outro arquivo versionado.

## Verificação

Em **Actions**, abra a execução mais recente de **GitHub Profile Summary Cards**. Se ela falhar, confira o log da etapa **Generate profile cards**, a validade do secret (se configurado) e as permissões de escrita do workflow, usadas para publicar os arquivos gerados.

Documentação do gerador: [github-profile-summary-cards](https://github.com/vn7n24fzkq/github-profile-summary-cards).
